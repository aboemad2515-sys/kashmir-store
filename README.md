# Kashmir Store / متجر كشمير

مرحبًا — هذا المستودع يحتوي على Scaffold أولي لمشروع متجر "كشمير" (موقع + API + تطبيق موبايل).

الوصف:
- اسم المتجر: Kashmir (كشمير)
- نطاق المنتجات: ساعات، شيلان، ملابس وإكسسوارات رجالية ونسائية
- طرق الدفع المبدئية: تحويل بنكي، عند الاستلام، PayPal
- بلد التشغيل: المملكة العربية السعودية

التقنية المقترحة (مبدئي):
- Web: Next.js (RTL)
- API: Node.js + Express (بنية بسيطة قابلة للتطوير لاحقًا إلى NestJS أو Django)
- Mobile: Flutter (iOS & Android)
- DB: PostgreSQL (سيتم إضافتها لاحقًا)

ماذا يوجد هنا الآن:
- scaffold لثلاثة مجلدات: /web, /api, /mobile
- README و ROADMAP للمراحل الأولى

الخطوات التالية (سأتابع):
1. فتح قائمة مهام (Issues) بالأسبوع الأول: إعداد بيئة محلية، نماذج المنتج، تسجيل دخول، عرض قائمة المنتجات، عربة الشراء.
2. إعداد بيئة CI بسيطة إن لزم.
3. إدخال أول 10 منتجات تجريبية لاختبار واجهات.

إذا أردت أي تعديل فورًا (اسم المستودع، خصوصية، أو مسار تقني)، أعلمني وسأطبقه.

# Roadmap - خطة العمل الأولية

- Initialize repo scaffold (web, api, mobile) ✅
- Setup development README and environment guidelines
- Create Issues: dev environment, sample product model, auth

Week 2

- Implement product list and product detail pages in web
- Implement basic product listing page in mobile

Week 4
- Integrate payment options (PayPal) + manual bank transfer option flow
- Implement admin content: simple product CRUD

Weeks 5-8
- Polishing UI/UX, RTL and Arabic content
- Shipping integration and pricing rules
- Add authentication & account pages, order history
- Testing and deployment setup

Note: Timeline is flexible and can be adjusted according to priorities.

# Mobile (Flutter) - README

هذا المجلد مخصّص لتطبيق Flutter (iOS & Android).

خطوات سريعة لبدء التطوير المحلي:
1. تأكد أنك منصّب Flutter SDK: https://flutter.dev/docs/get-started/install
2. من داخل المجلد mobile: `flutter create .` إذا لم تنشئ المشروع بعد.
3. شغّل التطبيق: `flutter run`

محتوى لاحق:
- سيتم إضافة `lib/main.dart` مع شاشة القوائم والتفاصيل
- سنستخدم نفس API (http://localhost:4000/api) أثناء التطوير
